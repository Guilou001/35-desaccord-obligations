# Protocole de l'extension

Le [protocole numérique](../config/selection_protocol.json) fixe les règles avant le calcul de l'extension. L'échantillon avait déjà été examiné dans le projet initial. L'analyse reste exploratoire.

La méthode complète, la correspondance à l'article, les résultats et les limites figurent dans la section d'extension de [l'article](../ARTICLE.md). Le [PDF](../rapport/rapport.pdf) est produit depuis cette même source.

Pour reproduire, utiliser `uv run desaccord selection` puis les commandes `verify` et `report` du dépôt. Les résultats de l'extension sont conservés dans un dossier distinct. La vérification contrôle aussi la conservation du repère initial.
